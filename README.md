# Фрирен

Пиксельный питомец для обычных веб-страниц. Основано на расширении «Луна».

1. Распакуйте ZIP-архив.
2. Откройте `chrome://extensions` в Chrome или `edge://extensions` в Edge.
3. Включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите папку `frieren-extension`.
4. Обновите открытую веб-страницу. Нажмите на персонажа для приветствия или перетащите его мышью.

В меню расширения можно выключить питомца, изменить размер, отключить прогулки и выбрать команду «Прыгни», «Сядь» или «Спи». Там же можно добавить свой спрайт-лист по шаблону. Настройки хранятся в браузере. На служебных страницах браузера и в магазине расширений питомец недоступен.
